# ABL-Assignment-Web-Development

This folder contains three beginner-friendly, responsive website projects built with **HTML5 and CSS3 only**.

## Projects
1. **Sweet Crumbs Bakery** (`project-1.html`) — bakery products, custom cake information, offers and contact details.
2. **NutriLife** (`project-2.html`) — healthy recipes, weekly meal planner, nutrition guide, tips and shopping list.
3. **The Urban Plate Café** (`project-3.html`) — restaurant menu, chef profiles, gallery, reviews, opening hours and reservation form layout.

## Technologies
- HTML5 for page structure and content
- CSS3 for colours, spacing, cards, hover effects, Flexbox/Grid and responsive media queries
- No JavaScript, frameworks or build tools

## How to open
1. Download or extract the project folder.
2. Double-click any `.html` file, or open it in a browser.
3. Resize the browser window to see the responsive layout on desktop, tablet and mobile widths.

## Important notes
- These are static front-end demonstrations. Forms are visual examples only; they do not send or save information.
- Product search, category filters, cart updates and reservation confirmations were removed because they require JavaScript or a back-end.
- Images are loaded from external image URLs, so an internet connection may be required to display them.
- Prices, reviews, offers and contact information are sample content for a student project.

## Student learning outcomes
This assignment demonstrates semantic HTML, internal navigation links, forms, tables, image use, reusable CSS classes, CSS Grid/Flexbox, hover states and media queries.

## Customisation
Edit the text and image URLs in each HTML file. Change the colours and layout in the `<style>` section to personalise the design.
